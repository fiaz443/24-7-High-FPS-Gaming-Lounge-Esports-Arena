🎮 High-Performance Gaming Lounge & Esports Arena Network

Project 1.4 | Cisco Packet Tracer | CCNA Networking Portfolio

📌 Project Overview

This project simulates a small-scale esports gaming lounge network using Cisco Packet Tracer. The network is designed to separate competitive gaming traffic from casual gaming and streaming activities, provide inter-VLAN connectivity, and prioritize tournament traffic on the WAN uplink during periods of network congestion.

The design follows a practical networking scenario in which an esports arena operations manager requires improved traffic management, network segmentation, and low-latency connectivity for competitive gaming.

🎯 Business Requirements

Protect tournament PCs from unnecessary traffic generated by casual gaming and streaming users.

Separate tournament, casual gaming, local game server, and streaming devices into dedicated VLANs.

Enable communication between VLANs through router-on-a-stick inter-VLAN routing.

Automatically assign IP addresses to gaming clients using DHCP.

Prioritize tournament traffic on the WAN interface using class-based QoS.

Provide outbound internet connectivity through NAT/PAT.

Verify network operation using connectivity tests and Cisco IOS show commands.
